# AI Agent Customization Slides

Local HTML slide deck for a developer knowledge-sharing talk about customizing AI agents with better context.

Open `slides.html` directly in a browser.

## Project structure

- `slides.html` - deck entrypoint
- `slides/` - slide content modules
- `images/` - slide images
- `docs/` - supporting source material
